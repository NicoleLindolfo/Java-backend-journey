# 🇺🇸 Technical English — Zero → B1 in 12 Months

English is part of the career, not a separate activity — documentation, interviews, and professional communication in the international market all require it.

> **Quick navigation:** [🗺 Go to the Roadmap](#roadmap) · [✅ Go to the Progress Checkpoints](#progress-checkpoints)

## Goal

Go from **zero** to **B1 (CEFR)** in 12 months, focused on technical English (reading documentation, writing READMEs/commits, interview communication).

## Required pace

CEFR estimates suggest around 350–400 study hours to go from zero to B1 — roughly **1 hour per day** of consistent practice.

## How this shows up in this repository

- **This entire repository is written in English from day one** — README, roadmap, commit messages, code comments. That's the practice: not a separate exercise, but the default language of the work itself.
- Early on, sentences may be simple or imperfect — that's expected and fine. The commit history itself becomes a visible record of improvement over time.

- [ ] **P0** — Subject pronouns and possessives (I/my, you/your, he/his...)
- [ ] **P0** — *There is / There are*

- [ ] **P1** — Imperative (important for commit messages: "Add", "Fix", "Update")

**Vocabulary**
- [ ] **P0** — Top 300 most common English words
- [ ] **P0** — Numbers, days, months, time

**Skills**

- [ ] **P0** — Future with *will* and *going to*
- [ ] **P0** — Modal verbs: can, could, should, must

- [ ] **P1** — Countable / uncountable nouns, *some / any / much / many*

**Vocabulary**
- [ ] **P0** — Top 1000 most common English words

- [ ] **P1** — Common phrasal verbs (set up, log in, turn on, find out, look for...)
- [ ] **P1** — Words for describing problems ("It doesn't work", "I get an error when...")

**Skills**
- [ ] **P0** — Reading: simple technical articles and error messages

- [ ] **P0** — Listening: beginner programming tutorials in English
- [ ] **P1** — Speaking: describe a project in 2–3 minutes

## Progress Checkpoints

At each checkpoint, check the challenges honestly. **If you can't complete most of them, don't move on yet** — spend extra weeks on the weak areas and re-test. Record the result in the [progress log](#progress-log) at the end.

> **Rule of thumb:** a checkpoint is passed when you complete at least **80%** of its challenges without a translator or AI help (use dictionaries only when stated).

### ✅ Checkpoint 1 — Month 2 (target: A1)

**Reading**
- [ ] Read a simple README (under 150 words) and explain in your own words what the project does
- [ ] Understand at least 70% of the words in a basic error message without translating

**Writing**
- [ ] Write 5–8 simple sentences introducing yourself (name, age, country, goals, what you are studying)
- [ ] Make at least 20 commits in this repository with clear English messages (e.g., `Add roadmap file`, `Fix typo in README`)

**Listening**
- [ ] Understand the main idea of a 2-minute slow video for beginners (with subtitles)

**Speaking**
- [ ] Record a 1-minute audio introducing yourself and talking about your daily routine

**Vocabulary**
- [ ] Know the 300 most common words and 50 technical terms (test with flashcards)

### ✅ Checkpoint 2 — Month 4 (target: solid A1 → early A2)

**Reading**
- [ ] Read a short beginner tutorial (e.g., "Getting Started" page of a tool) and list the steps in your own words

**Writing**
- [ ] Write a README for a small project: what it is, how to install, how to run
- [ ] Write a paragraph (6–10 sentences) about what you did last week, using past simple

**Listening**
- [ ] Follow a 5-minute beginner programming tutorial in English with subtitles, and take notes

**Speaking**
- [ ] Record a 2-minute audio describing one of your projects and why you are building it

**Vocabulary / Grammar**
- [ ] Use present simple, present continuous, and past simple correctly in writing
- [ ] Know 600+ words and 100+ technical terms

### ✅ Checkpoint 3 — Month 6 (target: A2)

**Reading**
- [ ] Read a technical blog post or documentation page (500+ words) and write a 5-sentence summary
- [ ] Read a Stack Overflow question and answer, and explain the solution

**Writing**
- [ ] Write a clear Stack Overflow-style question about a real problem (what you expected, what happened, what you tried)
- [ ] Write a complete English README with sections (description, features, setup, usage)

**Listening**
- [ ] Understand the main points of a 10-minute programming video with English subtitles

**Speaking**
- [ ] Record a 3-minute presentation of a project: problem, solution, technologies used
- [ ] Answer 5 basic questions aloud ("Tell me about yourself", "Why do you want to be a developer?", ...)

**Vocabulary / Grammar**
- [ ] Use modal verbs, future forms, and comparatives in writing
- [ ] Know 1000+ words and 150+ technical terms

### ✅ Checkpoint 4 — Month 8 (target: early B1)

**Reading**
- [ ] Read a section of official documentation (e.g., a Spring Boot guide) and implement what it describes
- [ ] Read a short technical article with only occasional dictionary use

**Writing**
- [ ] Write a Pull Request description (what changed, why, how to test)
- [ ] Write an English comment on a GitHub issue or discussion (real or simulated)

**Listening**
- [ ] Understand a 15–20 minute tech talk with English subtitles at normal speed

**Speaking**
- [ ] Do a 10-minute mock interview (recorded): introduction, background, project explanation, a technical concept in simple words
- [ ] Explain a technical concept you learned (e.g., what an API is, what a REST endpoint does) in 2–3 minutes

**Vocabulary / Grammar**
- [ ] Use present perfect and first conditional correctly in writing and speech
- [ ] Know 300+ technical terms

### ✅ Checkpoint 5 — Month 12 (target: consolidated B1)

**Reading**
- [ ] Read official documentation (Java, Spring Boot, AWS...) for a new topic and apply it, using translation only for rare words
- [ ] Read a job description in English and understand 90% of the requirements

**Writing**
- [ ] Write a technical document in English (design note, project documentation, or an Architecture Decision Record)
- [ ] Have your CV and LinkedIn profile fully written in English
- [ ] Write a professional email or message in English (introduction, follow-up, or asking a question)

**Listening**
- [ ] Understand the main ideas of a podcast or tech talk (20+ minutes) **without subtitles**
- [ ] Follow a live-coding or tutorial video without subtitles and understand what is being done

**Speaking**
- [ ] Complete a **30-minute mock technical interview** in English (behavioral + technical + questions for the interviewer)
- [ ] Explain your main project in English, including architecture decisions and challenges, for 5 minutes without reading

**Real-world use**
- [ ] Contribute to a real conversation in English (GitHub issue, community forum, Discord, or open-source discussion)
- [ ] Apply to at least 3 positions using English CV and cover message
